# Template Undangan Pernikahan Digital
Semua file berada dalam SATU folder (tidak perlu subfolder).

- index.html : katalog template + pembuat tautan
- undangan.html : halaman undangan untuk tamu
- katalog.css, katalog.js : gaya & logika katalog
- tema-undangan.css, render-undangan.js : gaya (5 tema) & logika undangan
- data.js : daftar template & data bawaan

Upload semua ke GitHub, aktifkan Settings > Pages (branch main, folder root).
Tambah template: tambah objek di data.js + kelas .t-<id> di tema-undangan.css.
