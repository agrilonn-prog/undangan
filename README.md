# Undangan Pernikahan Digital: 14 template lintas budaya & agama
Semua file dalam SATU folder. Upload ke GitHub, aktifkan Settings > Pages (branch main, root).
- index.html: katalog (filter), formulir, pratinjau, generator tautan massal
- undangan.html: halaman tamu
- data.js: daftar template, salam, kutipan; render-undangan.js: logika; tema-undangan.css: 14 tema
Tambah template: objek baru di data.js + kelas .t-<id> di tema-undangan.css.
Contoh tautan: undangan.html?t=islami&pria=Raka&wanita=Sinta&tanggal=2026-12-20T09:00&wa=62812xxx&bank=BCA&norek=123&an=Raka&to=Pak%20Budi
