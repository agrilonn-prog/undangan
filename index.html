Satu tamu per baris dengan format Nama|WhatsApp|Meja|Acara (semua setelah nama boleh dikosongkan; acara diisi akad atau resepsi). Nama dirapikan otomatis dan nomor 08… diubah ke 62…

    Pertanyaan umum

    Apakah data saya disimpan di server?

    Tidak. Data dasbor (tamu, anggaran, tugas) tersimpan di browser perangkat Anda. Gunakan perangkat yang sama, dan ekspor CSV sebagai cadangan.

    Apakah ucapan tamu terkumpul di satu tempat?

    Belum. Ucapan tersimpan di perangkat tiap tamu, dan RSVP dikirim lewat WhatsApp. Untuk kotak ucapan bersama dibutuhkan basis data online.

    Bisakah tautan dikunci agar tidak diteruskan?

    Tidak di versi statis ini. Pengunci tautan membutuhkan server untuk memeriksa tiap pembukaan.

    Cara memasang di GitHub Pages?

    Unggah semua file ke satu repo, lalu aktifkan Pages dari branch main.

    Dibuat dengan HTML, CSS, dan JavaScript biasa. Tanpa server.
